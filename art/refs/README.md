# Референсы

Для каждой сцены — своя папка: `art/refs/<scene>/` (`<scene>` — то же имя, что в `art/briefs/`).
Общие референсы стиля игры — `art/refs/_style/`.

## Что сюда класть
- Картинки любых размеров: png, jpg, webp, gif (скриншоты игр, арт, фото мест, палитры, мудборды).
- `notes.md` (по желанию): по строке на картинку — что в ней нравится («2.png — свет из окна», «5.jpg — палитра»), ссылки на страницы/видео, идеи сцены.

## Как Claude их смотрит
`python3 tools/ref_sheet.py <scene>` собирает все картинки в один лист `_sheet.jpg` — Claude открывает только его (дёшево по токенам) и читает `notes.md`. Ссылки открывает во встроенном браузере.
Файлы, начинающиеся с `_`, — служебные, в лист не попадают.
