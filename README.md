# Мера вины

«Мера вины» — сюжетный мистический детектив в пиксельном стиле. Нью-Йорк, 1998 год. Полицейский Алексей Карамазов расследует серию смертей, связанных с теми, кто избежал наказания. Кто же является убийцей?

## Запуск

Нужен **Godot 4.7.2** с поддержкой рендерера Forward+. Импортируйте корневой файл `project.godot` в менеджере проектов Godot. Дождитесь импорта ресурсов и нажмите **F5** для запуска с главного меню.

### Первый запуск на другом компьютере

В свежем клоне Godot сам создаёт кэш `.godot/`. При первом открытии дождитесь окончания импорта. Если в начале импорта появляется ошибка загрузки шрифта Pixeloid, дождитесь завершения и заново откройте проект. Из корня проекта импорт и короткую проверку запуска можно выполнить командами:

```bash
godot --headless --path . --import
godot --headless --path . --quit-after 120
```

Если компьютер не запускает Forward+, попробуйте запустить игру с рендерером Compatibility:

```bash
godot --path . --rendering-method gl_compatibility
```

В Compatibility освещение и эффекты в 3D-сценах могут выглядеть иначе. [Требования Godot к оборудованию](https://docs.godotengine.org/en/latest/about/system_requirements.html)

## Управление

| Действие | Клавиши по умолчанию |
| --- | --- |
| Перемещение | WASD или стрелки |
| Взаимодействие | E |
| Инвентарь | I |
| Фонарь в сценах, где он доступен | F |
| Пауза | Esc |
| Выстрел в бою | ЛКМ |
| Рывок в бою | Пробел или Shift |
| Перезарядка | R |
| Выбросить предмет | I → выбрать предмет → «Выбросить» |
| Поднять выброшенный предмет | G или клик по подсказке |

Клавиши можно изменить в меню **Настройки → Клавиши**. Игра делает автосохранения при переходах в поддерживаемые сцены. Ручные слоты доступны из меню паузы.

## Структура проекта

| Папка | Содержимое |
| --- | --- |
| `scenes/` | Сюжетные главы, меню и игровые сцены |
| `scripts/` | GDScript для сцен, интерфейса, боя и общих систем |
| `data/` | Диалоги и описания предметов |
| `assets/` | Графика, модели, шрифты и звук |
| `tests/` | Автотесты, запускаемые через Godot |
| `docs/` | Дизайн, постановка сцен и настройка среды |

## Тесты

Если Godot установлен под другим именем, используйте полный путь к исполняемому файлу. Тесты используют отдельную папку сохранений.
