# Style Guide (Э2, по пробе стиля s01; ходьба/персонажи — дополним позже)

| Параметр | Значение |
|---|---|
| Базовое разрешение | **640×360** (×3 = 1920×1080), integer scale — DECISIONS #5 |
| Вид | Статичные кинокадры сбоку / 3/4 (экспозиция), строго сверху (стол); ходьба — позже, вид уточним в сцене с ходьбой |
| Палитра | Строгой нет (DECISIONS #6): полные цвета, уменьшение box-фильтром. Насыщенность не снижаем |
| Контур | Без контура у фонов; у мелких объектов — тёмный край по свету, не чёрная обводка |
| Освещение | Ночь, почти темно. Один тёплый источник (настольная лампа) + холодный синий свет из окон, дождь. Глубокие тени |
| Настроение | нуар, одиночество, усталость, тревога, дождливая ночь |
| Время/место | Нью-Йорк, 1998 |
| Референсы | `art/refs/_style/` (атмосфера, Final Run), `art/refs/s01_precinct/` (подача сцен и UI) |
| Эталон стиля | `art/style_ref.png` (исходник фона экспозиции s01) |
| Текст в картинках | **Никогда.** Все надписи (газета, дело, записка) рисует Godot шрифтом поверх ассета; в генерации — пустые поля / неразборчивые строки |

## Базовый промпт стиля (Codex добавляет к каждой генерации)
```
high-detail pixel art matching the style reference, <вид>, night, noir, rainy New York 1998,
moody low-key lighting: one warm desk lamp + cold blue window light, deep shadows, light haze,
crisp uniform square pixels, no text, no letters, no watermark, no frame,
<для объектов: solid flat #FF00FF background, centered> / <для фонов: full opaque scene, 16:9>
```
