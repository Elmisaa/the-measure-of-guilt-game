# Style Guide (заполняется на этапе Э2, утверждается пользователем)

| Параметр | Значение |
|---|---|
| Базовое разрешение | 320×180 / 480×270 / 640×360 — выбрать |
| Размер тайла | 16 / 32 px — выбрать |
| Размер персонажа | например 16×24 или 32×32 |
| Вид | сбоку (платформер) / сверху (top-down) / 3/4 |
| Палитра | название с lospec.com, файл `art/palette.png`, N цветов |
| Контур | тёмный 1 px / цветной / без контура |
| Освещение | источник сверху-слева, 2–3 тона на материал |
| Настроение | 3–5 слов |
| Референсы | ссылки или файлы `art/refs/` |
| Эталон стиля | `art/style_ref.png` |

## Базовый промпт стиля (Codex добавляет к каждой генерации)
```
pixel art, <вид>, <настроение>, limited palette matching the reference,
crisp uniform square pixels, no anti-aliasing, no blur, no gradients, no dithering noise,
<контур>, solid flat #FF00FF background, centered, no text, no frame
```
