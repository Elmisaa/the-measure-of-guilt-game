# Разделение работы: Claude / Codex / скрипты / пользователь

Принцип: **Claude думает и координирует, Codex рисует и делает объём, скрипты делают механику.**
Codex тратит лимит ChatGPT Plus, а не лимит Claude, поэтому всё, что не требует глубокого понимания проекта, по умолчанию уходит туда.

## Как Claude вызывает Codex

**Графика** (одна задача на один ассет или небольшую группу):
```bash
codex exec --full-auto -i art/style_ref.png "\$imagegen <задача по шаблону ниже>"
```
или через субагента плагина: `/codex:rescue --background <задача>`.

**Код/данные/тесты:** `/codex:rescue --background <задача>`; результат: `/codex:status`, `/codex:result`.

**Ревью:** `/codex:review --base main` (или `--background`).

## Шаблон задачи для Codex
Короткий, без лишнего контекста: Codex сам прочитает `AGENTS.md`.
```
Задача: <одно предложение>
Читай: <1–3 файла: ТЗ / образец / STYLE_GUIDE>
Сделай: <конкретно, с размерами/количеством>
Положи: <пути>
Не трогай: <что нельзя менять>
Готово, когда: <критерий проверки>
```

Пример (графика):
```
Задача: черновики спрайта героя в покое.
Читай: art/briefs/forest.md (ассет hero_idle), docs/STYLE_GUIDE.md
Сделай: 3 варианта спрайт-листа 4 кадра в одну строку, фон #FF00FF, референс art/style_ref.png
Положи: art/drafts/hero_idle/v1_{a,b,c}.png + README.md с промптом
Готово, когда: 3 файла существуют
```

## Бюджет
- Не больше 10 генераций картинок за одну задачу без согласия пользователя.
- Сначала 1 ассет на пробу, потом пакет, особенно в начале проекта.
- Review gate (`/codex:setup --enable-review-gate`) **выключен**: включать только по просьбе пользователя.
