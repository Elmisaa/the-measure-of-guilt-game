# План реализации: зал с ходьбой (s01)
Статус: DRAFT — на согласовании. Графика APPROVED: `assets/backgrounds/s01/walk_hall.png` (2012×360, пиксель 4x), `assets/characters/alexei/walk_side.png` (10 кадров: 0–1 стоит, 2–9 шаг; кадр 24×50 арт-пикс ×4 ≈ 200 px), схема `art/refs/s01_precinct/plan/walk_layout_v2.png`.

## Место в сюжете [вопрос]
Вариант А: экспозиция → **зал с ходьбой** (свободно исследовать) → сесть за стол → документы, компьютер, рапорт → звонок.
Вариант Б: экспозиция → стол (как сейчас) → после рапорта встать и пройтись → звонок застаёт в зале.

## Управление
- A/D или ←/→ — идти, Shift — не нужен (медленный темп). Клик мышью по полу — идти к точке (по желанию).
- E/Пробел или клик по подсвеченному предмету рядом — взаимодействие. Подсказки как сейчас: блик + уголки, но только когда Алексей рядом.

## Сцена `scenes/s01/walk.tscn`
- Фон-спрайт 2012×360; Camera2D следует за Алексеем по X, ограничена краями (0…2012), сдвиги по 4 px (без дрожания пикселей).
- Алексей: `CharacterBody2D` или простой Node2D + AnimatedSprite2D (stand/walk), отражение для движения влево, скорость ~70 px/с, коллизия только по X (стены — края сцены).
- Свет: CanvasModulate (темнее) + PointLight2D у лампы Алексея (мерцание, как в экспозиции), холодный свет у левого края, зелёная лампа (мигает), дождь в тёплых окнах (WindowRain) — по желанию.
- Передний план — позже отдельным слоем (параллакс).
