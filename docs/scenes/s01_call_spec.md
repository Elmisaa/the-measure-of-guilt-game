# План реализации: звонок Фёдора (s01, часть 3)
Статус: РЕАЛИЗОВАНО (черновые звуки), на оценке. Мелодия — horror-beneath-the-silence; кнопка — «Взять вещи и уйти» (временно). Тексты — дословно из материала пользователя (`s01_precinct_design.md`, «Звонок Фёдора»). Всё, помеченное [предложение], — идеи Claude.

## Поток
1. Стол: клик «Ответить на звонок» → звонок обрывается, короткое затемнение → **кадр звонка** (`call_bg` + слой `call_alexei_desk`).
2. Реплики по клику/пробелу, как в экспозиции (печать по буквам, «блипы»):
   - **Фёдор** (голос из трубки): [предложение] плашка у трубки слева сверху от головы Алексея, имя «Фёдор» своим цветом, «блипы» ниже и с лёгким треском; буквы его реплик слегка дрожат.
   - **Алёша**: над головой Алексея, как в экспозиции.
3. С первой реплики Фёдора стартует «жуткая мелодия» (какой файл — см. вопросы).
4. **Нарастание напряжения без эмоций героя** [предложение] — по номеру реплики растут:
   - мерцание настольной лампы (сначала редко, к концу часто);
   - дрожание букв реплик Фёдора;
   - помехи на экране: шум + горизонтальные «срывы» строк (шейдер поверх кадра), короткие вспышки на восклицаниях;
   - лёгкое подёргивание кадра на 1–2 px на фразах с «!».
5. **Удар в дверь**: звук удара; кадр резко дёргается, лампа гаснет на ~0.3 с, вспышка помех; затем «ДМИТРИЙ?! ЧТО ТЫ ДЕЛАЕШЬ?!» крупнее и дрожит сильнее всех.
6. **Обрыв**: музыка обрывается, звук падения трубки/щелчок → **гудки** (долгие, монотонные, в цикле); помехи гаснут, лампа горит ровно.
7. **Реакция Алёши** (мысли внизу, ThoughtBox): «Отец никогда не говорил мне об этом. Виктор Мерсер... Партнёр отца. Что они сделали в 1991 году?» → «И этот удар в дверь... Кто это? Виктор? Дмитрий? Или кто-то ещё?»
8. Кнопка действия «Взять вещи и уйти» → гудки стихают → монолог «Если они действительно замешаны…» → затемнение. Кадр «Алёша встаёт, силуэт на фоне окна» — отдельная графика, следующим шагом; пока — затемнение и заглушка «продолжение следует».
9. История диалогов пишет все реплики; задание (иконка) обновляется без уведомлений.

## Технически
- Сцена `scenes/s01/call.tscn`, скрипт `scripts/s01/call.gd`; реплики — `data/dialogues/s01_precinct.json` → `call.lines` (тип say / think / event: knock, hangup).
- Повторно используем: ThoughtBox, SceneRouter, Audio (музыка/петли), LightFlicker + затемнение лампы, Jitter.
- Новое: шейдер помех `scripts/fx/screen_glitch.gdshader` (CanvasLayer поверх кадра), дрожащий текст (`RichTextLabel` + свой эффект или Label с посимвольным сдвигом).
- Звуки: удар в дверь, щелчок/падение трубки, гудки — [предложение] синтезирую скриптом (`tools/`) как черновик; если есть свои — заменим.
- Тест `tests/test_s01_call.gd`: проход всех реплик → событие удара → гудки → кнопка → затемнение.
