## 9. Шрифт: Pixeloid (2026-11-18)
Pixeloid Sans / Sans Bold / Mono (GGBotNet, SIL OFL 1.1), 9 px. Файлы и лицензия — `assets/fonts/pixeloid/`. Указать в титрах.

## 10. Каркас сцен: SceneRouter + тексты в JSON (2026-11-18)
- Автозагрузка `SceneRouter` (`scripts/autoload/scene_router.gd`): переходы между сценами с затемнением, `SceneRouter.go_to(path)`.
- Реплики, мысли, подсказки — в `data/dialogues/<scene>.json` (загрузчик `DialogueData`). При экспорте добавить `*.json` в фильтр ресурсов.
- Общая тема UI `assets/ui/main_theme.tres` (Pixeloid 9px, без сглаживания), снап 2D к пикселям.
- UI-компоненты: `HintMarker` (мигающий маркер-мысль), `ThoughtBox` (мысли снизу).

## 11. Освещение и art/.gdignore (2026-11-18)
- Динамический свет — PointLight2D + `LightFlicker` (`scripts/fx/`), текстура света — радиальный градиент. Свет слабый, чтобы не менять палитру фонов.
- `art/.gdignore`: Godot не импортирует исходники/черновики/референсы; в игру идёт только `assets/`.

## 12. Пиксель 2x (2026-11-18)
Все картинки сцен — «средний пиксель»: 1 арт-пиксель = 2×2 базовых (эффективно 320×180, экран 640×360). Цвета не меняются: `tools/chunky.py` (box ↓2, nearest ↑2). Спрайты/анимации — рендер в половинном размере и ×2 (`rotor_frames.py --scale 2`). Позиции объектов и маркеров — на чётных координатах. Текст UI остаётся в 1px-сетке (шрифт 9px). 1x-версии — в `art/sources/s01/*_1x.png`.

## 13. Кат-сцены: Letterbox + s00 (2026-11-18)
- Автозагрузка `Letterbox` (`scripts/autoload/letterbox.gd`): кинополосы 44px; `show_bars()`, `retract()` (верхняя уходит вверх, нижняя вниз). Следующая сцена сама убирает полосы, если они показаны.
- Игра стартует с `scenes/s00/intro.tscn`. Кадры кат-сцен 680×290 (запас под панораму по 2px), видимая область 640×272.
- «Оживление» нарисованного кадра без новых кадров анимации: шейдер `write_wobble.gdshader` сдвигает мягкую область (рука) по сетке 2px.

## 14. Пиксель кат-сцен 4x (2026-11-18)
Кадры кат-сцены s00 — «крупный пиксель» 4x (эффективно 170×73 на видимую область); сетка руки/дождя/пара — 4px. Игровые сцены остаются 2x (DECISIONS #12). Цвета не меняются (box ↓, nearest ↑).

## 15. Звук (2026-11-18)
- Автозагрузка `Audio`: с запуска игры — эмбиент дождя с громом (freesound 877124, ищется по id; если файла нет — Star Gazers), зациклена, -10 dB, плавное появление; звуки речи — короткий «блип» (`tools/make_blip.py`) каждые 2 буквы при печати реплики, высота голоса на персонажа (`voice_pitch` в JSON).
- Аудио лежит в `assets/audio/{music,sfx}`; папка пользователя `sounds/` перенесена туда. Лицензии — `docs/CREDITS.md`.
- s00 начинается с цитаты на чёрном (пропустить нельзя) (`data/dialogues/s00_intro.json`): появление 1.6 с, 6 с на чтение, исчезновение 1.6 с.

## 16. HUD (2026-11-18)
- Автозагрузка `Hud`: справа сверху иконки «задание» (наведение/клик — текущее задание; при смене задания — без уведомлений) и «история» (клик — журнал реплик и мыслей, Esc/клик мимо — закрыть). Иконки 12×12 арт-пикс ×2 (Codex), `assets/ui/icon_*.png`.
- Задания — `objective` в JSON сцены. Журнал пишется автоматически: реплики (exposition) и все мысли (ThoughtBox).
- Звуки UI: `ui_hover`/`ui_click` (`tools/make_ui_sounds.py`), подключение — `Audio.bind_button(control)`.
- В скриптах с class_name не обращаться к автозагрузкам по имени (в тестах `-s` они компилируются раньше) — брать через `/root/<Имя>`.

## 17. Тесты не мешают пользователю (2026-11-18)
Автотесты гонять `--headless`. Скриншоты — только с окном за экраном: `--position 20000,20000`. В каждом тесте — `SAFETY_TIMEOUT` (90 с), чтобы окно никогда не зависало.

## 18. Длинный текст — по страницам (2026-11-18)
`TextPager.pages(text, max_chars)` режет текст по предложениям (~80–90 символов на страницу); следующая страница — пробел/клик. Используется в звонке (реплики и мысли) и в реакциях на документы. В историю пишется полный текст. Если есть продолжение — в плашке мигает «...». Документ нельзя закрыть (ни кликом, ни Esc), пока мысли Алексея не дочитаны до конца.

## 19. Аудио в репозитории — OGG (2026-11-18)
Длинные треки/эмбиенты кладём в игру как OGG Vorbis высокого качества (`tools/to_ogg.py`, ~240 кбит/с, на слух как оригинал); оригиналы WAV — локально в `art/sources/audio/` (в git не идут). Лимит GitHub — 100 МБ на файл.

## 20. Решения игрока и компьютер (2026-11-18)
- Автозагрузка `GameState` — флаги и решения игрока (`set_flag/get_flag`) для будущих сцен.
- `Terminal` (CanvasLayer, код без графики) — внутриигровой компьютер 1998 г.; `ClickZone` — кликабельная зона поверх нарисованного предмета.
- Порядок на столе: 3 документа → рапорт в компьютере (выбор) → звонок.

## 21. Язык и подсказки (2026-11-18)
- Весь текст в игре пока по-русски, включая имена, шапки документов и надписи «в мире» (решение пользователя; отменяет правило «надписи по-английски»).
- Интерактивные предметы без маркеров: зона по размеру предмета, на наведении — тонкие уголки-скобки и курсор-рука (`HintMarker`). Блик по предмету отключён по просьбе пользователя (`glint_enabled = false`). Документы на столе — подъём при наведении.

## 22. Зал с ходьбой (2026-11-19)
- Порядок s01: экспозиция → стол (документы, компьютер, рапорт) → «Нужен кофе» → **зал с ходьбой** (вид сбоку, пиксель 4x, Алексей ~200 px) → кофе, вторая кружка → звонит телефон у стола → вернуться, ответить → звонок отца.
- `WalkPlayer` (A/D/стрелки, шаг по сетке 4 px), `walk.gd` (места из `data/dialogues/s01_walk.json`, подсказки только рядом с Алексеем, E/пробел/клик), камера по X в границах зала.

## 23. Ходьба: глубина + свет (2026-11-19)
- Анимация из частей тела (скелетная) пробовалась и отклонена пользователем — удалена. Алексей — прежний спрайт `walk_side.png` (10 кадров), для глубины — `walk_side_depth.png` (тот же спрайт в 3 размерах).
- Бег: Shift (175 px/с против 90 шагом, анимация быстрее).
- Глубина: W/S — шаг к стене и обратно; дальше = меньше, по заранее подготовленным размерам (строки листа 1.0/0.97/0.94 — разница небольшая, по просьбе пользователя), без масштабирования в движке.
- Свет зала: CanvasModulate (темнее) + PointLight2D: лампа Алексея, две зелёные лампы (мигают), тёплые окна, холодный свет слева; свет ложится и на Алексея.
- Порядок: кофе → вторая кружка → «пора домой» → свободное исследование → вещи у стола → звонок там же.

## 24. Инвентарь, выносливость, радио (2026-11-19)
- Тир в подвале — **необязательная** локация (схема `art/refs/s01_range/plan/`), прорабатываем позже.
- Инвентарь: клавиша I / иконка в HUD, открывается всегда, кроме диалогов. Подсказка при наведении: название, описание, действия; клик — меню действий, у каждого — мысль Алексея.
- Стартовые предметы: пустая кружка (у кофемашины → «Налить кофе» → «Выпить» = мысль + полная выносливость), пистолет, бинт (лечение — когда появится здоровье), дубинка, фото семьи (крупный план). На фото: сзади отец и мать, спереди три сына (младший — Алексей).
- Выносливость: полоска только во время бега/восстановления; на нуле — шаг и выдох.
- Бег: отдельная анимация (Codex, 8 кадров), строки глубины скриптом.
- Музыка: радиоприёмник в зале (станции, в т.ч. «странные», шипение между ними, тише вдали). Плеер (Walkman) — позже.

## 25. Кружка, прыжок, туалет, станция (2026-11-19)
- Рапорт: одна мысль на выбор, следующий вопрос сразу (без ожидания).
- В зале пробел = только прыжок (анимация 5 кадров, вариант a); действие — E/клик.
- После рапорта: мысль «свежий кофе» → кнопка «Взять кружку» (кружка со старым кофе, HUD «Взято: …» слева сверху) → «Встать» → зал. Кружку сначала моют в туалете, потом кофемашина, потом выпить из инвентаря.
- Новая дверь в туалет в зале + локация туалета (схема `art/refs/s01_restroom/plan/`).
- Странная станция: только шум, над радио «Странная станция» и код по одной цифре (4719).
- Дочка Сары — Эмили.

## 26. Предметы зала, ящики, туалет (2026-11-19)
- Схемы `walk_props_v1` и `restroom_layout_v1` утверждены. Дверь в туалет дорисована в зал (Codex, правка), фон зала до правки — `art/sources/s01/walk/walk_hall_before_door.png`.
- Места зала по типам (`kind` в `s01_walk.json`): `closeup` (крупный план, текст рисует игра: `text`/`text_rect` или несколько `texts`), `container` (ящик/шкафчик/доска — окно как инвентарь, «Взять»/«Взять всё»; ящик Сары — только осмотр), `door` (в другую комнату; состояние зала, место у двери и станция радио сохраняются во флагах).
- Если рядом несколько мест — E берёт ближайшее, под мышью — то, на которое наведено.
- «Пора домой»: сначала вещи из своего шкафчика (ключи, блокнот, зонт; кассета — необязательно) → вернуться к столу → выключить лампу → звонок.
- Туалет — отдельная сцена (`scenes/s01/restroom.tscn`): раковина моет кружку, мысли у зеркала, кабинок, сушилки.

## 27. Предмет в руке, осмотр поверх инвентаря (2026-11-19)
- Кружку (и потом другие предметы) берут в руку: инвентарь → «Взять в руку»; иконка идёт за мышью, сверху «В руке: …»; E/клик по месту — применить (раковина моет кружку со старым кофе, кофемашина наливает в чистую), ПКМ/Esc — убрать. С пустыми руками там только подсказка.
- «Осмотреть» в инвентаре/ящике не закрывает окно: мысль или крупный план поверх, после — окно на месте.
- Крупные планы и у предметов из инвентаря: блокнот Алексея (список «Весов»), кассета («Для А. К.»), рисунок Эмили, образцы почерка, пистолет с жетоном.
- Подпись странной станции — как реплика (имя мелко цветом, цифры крупно белым, без плашки), высоко над радио, не перекрывает Алексея.

## 28. Зал s01: бег, выносливость, обучение (2026-11-19, правка — §29)
- Шкафчик открывается сразу, вещи из него берутся только после второго кофе («Вещи заберу потом. Сначала кофе.»). Предмет в руке не мешает: у других мест он убирается в сумку.

## 29. Управление и подсказки (2026-11-19)
- Прыжка нет. Пробел — только для диалогов и мыслей. Ходьба 108 px/с (×1,2), бег 315 px/с (×1,8 от прежних 175), запас бега 14 с.

## 31. Курсор и масштаб (2026-11-19)
- Курсор системный (пиксельные курсоры убраны по просьбе пользователя). При ходьбе курсор по-прежнему скрыт.
- Масштаб `fractional`: картинка заполняет окно без чёрных полей. При соотношении сторон не 16:9 остаются тонкие полосы на одной оси. Целочисленный масштаб с рамкой — опция «Чёткие пиксели» в настройках.
- Главный экран — на весь экран (фон зала участка), без кинополос. Кинополосы остаются только в кат-сцене s00.

## 32. Курсор, меню паузы, сохранения (2026-11-22, по просьбе пользователя)
- Курсор снова свой, но новый и маленький: пиксельное «перо» 16×16 (Codex). Над кликабельным оно становится янтарным, с искрой (форма POINTING_HAND). Масштаб курсора — целый, по высоте окна (1x на 360 px). Курсор виден везде, в том числе при ходьбе; места в зале и туалете кликаются, если Алексей рядом (E тоже работает). Предмет в руке следует за курсором.
- Иконки «Задание», «История» и «Вещи» справа сверху убраны. Всё это в меню по Esc: Продолжить / Задания (текущее и выполненные) / История диалогов / Вещи / Управление / Сохранить / Загрузить / Настройки / В главное меню. Плашка задания по-прежнему на 5 с всплывает справа сверху при входе в сцену.
- При входе в зал (не при возвращении из туалета) слева на ~9 с появляется панель «Управление».
- Сохранения: автозагрузка `SaveGame`, JSON в `user://saves/` (тесты — `user://saves_test/`), автосохранение + 3 слота. В сохранении: сцена (при загрузке начинается заново), GameState (флаги, вещи, ящики, силы), журнал (задание, выполненные, история). Сцена может добавить свой прогресс через `save_state()`: в зале — позиция Алексея и шаг истории, на столе — прочитанные документы, рапорт, лампа. Автосохранение — при каждом входе в игровую сцену. На главном экране «Продолжить» (последнее сохранение) и «Загрузить».
- Стол: лампу можно выключать и включать (клик по лампе). Комната уходит в ночной синий, документы читаются тускло, и Алексей это комментирует.
- База данных: +6 человек (Роза Альварес, Мэри Грейди, Тони Руссо, Хелен Вебер, Линда Чен, Дэниел Окафор) — лор-черновик. В поиске — подсказка и 4 кликабельных имени, которые ещё не искали.
- Окна зала: город за стеклом смещается медленнее комнаты (параллакс 0,14, по сетке 4 px). Рамы и колонна стоят на месте (`tools/make_window_parallax.py` + шейдер `window_parallax.gdshader`).

## 33. Зал после правок (2026-11-22, по просьбе пользователя)
