# Правила работы с проектом «Мера вины»

- Проект использует Godot 4.7.2, GDScript и базовое разрешение 640×360.
- Работай в рамках задачи. Переиспользуй существующие сцены, компоненты и формат данных. Сохраняй пользовательские правки.
- Согласуй изменения архитектуры, настроек проекта и формата сохранений, если задача их явно не предусматривает.
- Используй статическую типизацию GDScript, `snake_case` для файлов и `PascalCase` для классов. При правке сцен и ресурсов сохраняй их формат и ссылки.
- Проверяй изменения кода в Godot. Если проверка зависит от окна или рендерера, укажи, что удалось проверить.
- Для нового арта используй [гайд по стилю](docs/STYLE_GUIDE.md), ТЗ и референсы сцены. Черновики сохраняй в `art/drafts/`. В `assets/` размещай утверждённые или предоставленные пользователем материалы, которые нужно подключить к игре.

Команды проверки, правила подготовки арта и структура проекта описаны в [руководстве по работе с проектом](docs/AGENT_GUIDE.md). Для боевой механики действуют также [правила геймплея](scripts/gameplay/AGENTS.md).
